## 🎯 How to Use This Repository

1. **Start with Chapter 1** - Begin with Python basics to understand fundamental concepts
2. **Progress sequentially** - Each chapter builds on previous knowledge
3. **Read theory files** - Files with numbers (01_, 02_, etc.) contain explanatory code and concepts
4. **Practice with problems** - Solve problems in the "Problems" and "Practice" folders
5. **Review Syntax folder** - Reference advanced topics as needed

## 🔧 Prerequisites

- Python 3.x installed on your system
- A code editor or IDE (VS Code, PyCharm, etc.)

## 📝 File Organization Notes

- **Theory files**: Named with numbers (01_, 02_, etc.) contain explanations and examples
- **Problem files**: Named `problem_*.py` or `*.py` in Problems/Practice folders contain exercises
- **Jupyter notebooks** (`.ipynb`): Interactive Python notebooks in the Practice folder

## 🚀 Running the Code

To run any Python file:
```bash
python filename.py
```

To run Jupyter notebooks:
```bash
jupyter notebook filename.ipynb
```
